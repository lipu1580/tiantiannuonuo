按我们现有的器件，我建议先固定一套控制方式：**按键负责选音和音色，五片 FSR402 负责触发，另一片 FSR 负责持续力度，电位器负责滑音。** 这样各个输入的作用清晰，三个人也容易分工。

先纠正之前的一处错误：**ADS7830 是 8 路、8 位、I²C 接口的 ADC，使用 SDA、SCL，不是 SPI。** 之前回复和接口文档中提到的“ADS7830 SPI 驱动”需要改为 I²C 驱动；它读出的原始数值范围是 **0～255**。

| 输入设备 | 建议作用 | FPGA 最终得到什么 |
|---|---|---|
| 4×4 按键矩阵 | 选择音区、音阶、音色 | 音符映射、`waveform_sel` 等设置 |
| 五片 FSR402 | 检测五处按压，压力大小即力度 | `NOTE_ON`、音符编号、`velocity` |
| FSR402 | 持续控制正在发声的音符强弱 | `expression` |
| 电位器 | 连续升降音高 | `pitch_bend` |
| ADS7830 | 将模拟电压转换成数字 | 通道编号、8 位采样值 |

**1. 按键矩阵：决定接下来弹什么音、用什么音色**

例如先规定五片 FSR 对应 C4、D4、E4、G4、A4。按“升八度”键以后，它们变成 C5、D5、E5、G5、A5；按音色键，可以切换两套合成参数。

基本逻辑是：

```text
逐行扫描按键 → 消抖 → 检测新按下的键 → 更新音区或音色设置
```

成员 2 保存每片 FSR 对应的 `note_id`，触发时再发送这个编号。建议音区设置只影响后续新触发的音符，已经发出的音保持原音高，避免意外跳音。

这套方案中矩阵主要用于单键设置，能降低多键鬼键的影响。普通封装薄膜矩阵通常无法在外部简单加 16 个二极管实现逐键防鬼键，之前的建议不够准确。

**2. 五片 FSR：决定什么时候开始发声**

FSR402 是压力传感器，一端接 3.3 V、另一端接 ADC，每路再加一个 10 kΩ 到 GND。
按压时阻值下降、节点电压升高。安装时把 FSR 贴在每个演奏区下方，
上面盖一片硬质小圆片分散手指压力。

每一路的基本逻辑是：

```text
FSR 分压 → ADC → 电平 ≥ 阈值 → 发送 NOTE_ON（锁存音符与力度）
              → 电平低于释放阈值持续若干样本 → 发送 NOTE_OFF
```

压力大小直接映射成 `velocity`：轻按较小，重按较大。与压电不同，
FSR 不需要峰值保持、钳位或放电电路，因为按压期间电压持续存在。

五路必须各自保存阈值、释放计数和防重复触发状态。防重复触发窗口
放在首次触发之后，避免一次按压产生多个 NOTE_ON。

FSR 能真实反映“还按着 / 已松开”，所以 NOTE_OFF 由电平判定，
不需要再靠定时器猜；定时器只作为 ADC 断线时的兜底。

**3. FSR402：控制声音持续变化的强弱**

一个 FSR 可以控制所有正在发声的声部，例如左手按住 FSR，右手指按触发 FSR：

```text
FSR + 分压电阻 → ADC → 校准、轻度滤波 → expression
```

轻压时整体声音较弱，重压时较强。它和触发 FSR 的区别是：`velocity` 在每次触发时记录一次，`expression` 会在发声期间持续更新。

只有一个 FSR 时，这个控制通常是全局的，不能分别判断五根弦各自的持续按压力。初期也可以把它映射到非零音量范围，避免松开 FSR 后整件乐器完全无声。

**4. 电位器：控制滑音**

电位器两端接合适的供电和地，中间抽头接 ADC。建议先固定为滑音旋钮：中间不变，向左降音，向右升音，例如最大变化为上下两个半音。

```text
电位器 → ADC → 中心死区、平滑 → pitch_bend
      → 音频核心调整正在发声声部的频率
```

中心死区可以防止手不动时音高漂移。按半音控制时，频率关系为 `新频率 = 原频率 × 2^(半音变化/12)`，FPGA 可以用查表和乘法实现。一个旋钮只能提供一个独立连续参数，切换模式可以兼任音量，但无法同时独立调整音量和滑音。

**5. ADS7830：负责轮流读取这些模拟输入**

通道分配：CH0 读取 FSR 表情，CH1 读取电位器，CH2~CH6 读取五路触发 FSR，
CH7 备用。成员 2 编写 I²C 控制器，选择通道、读取数值，再分发给对应处理模块。

> 该映射与 `project_params.svh` 中的 `FSR_ADC_CHANNEL=0`、`POT_ADC_CHANNEL=1`、
> `TRIGGER_ADC_CHANNEL_BASE=2` 一致。

它是轮流采样，不是七路同时采样。FSR 电压是持续量，1.2 kHz 的轮询率对按压
动作完全够用；不像压电尖峰那样必须做峰值保持。

最终成员 2 交给成员 1 的信息可以整理为：

| 信息 | 作用 |
|---|---|
| `NOTE_ON + note_id + velocity` | 开始一个指定音高、指定初始力度的音符 |
| `NOTE_OFF + 音符标识` | 让对应音符进入释放阶段 |
| `expression` | 持续改变声音强弱 |
| `pitch_bend` | 连续改变正在发声的音高 |
| 音色选择 | 切换波形、包络或合成参数组合 |

演奏时就是：**按键选好音区和音色，拨动压电片发声，按压 FSR 改变强弱，转动电位器改变音高。** 音频核心收到这些控制信息后，独立完成振荡器、ADSR、混音和逐样本输出。
