# 更新版硬件清单（含压电输入保护与调理）

更新时间：2026-10-19  
适用方案：5 片压电片做拨动/敲击触发，FSR402 做持续力度，电位器做滑音，
4×4 矩阵做音区/音色选择，ADS7830 做模拟采集，MAX98357 + 无源扬声器做音频输出。

---

## 0. 先回答压电片的问题

**不要用电感去“中和”压电片的尖峰。** 压电片等效为一个电容（约 10~20 nF），
串联电感会与它形成 LC 谐振，可能把尖峰放大并产生振铃，反而更危险。

压电片受迫时输出的是**高电压、短脉冲**（可能 ±几十伏），FPGA 引脚绝对最大
范围只有 -0.3 V ~ 3.6 V。正确的做法是四件事：

1. **限流**：每路串联 1 kΩ，限制进入钳位二极管的电流。
2. **钳位**：用 BAT54S 双肖特基把信号夹在 0 V ~ 3.3 V，再加 3.3 V TVS/稳压管吸收能量。
3. **泄放**：压电片两端并 1 MΩ，给压电片自身电容提供直流泄放路径。
4. **低通/峰值保持**：1 nF 就近到地吸收高频；100 nF 做峰值保持，供 ADS7830 慢慢采样。

电容有用，但**不能只靠一个大电容**把尖峰“吃掉”；关键是把电压钳在安全范围。
电感只在 MAX98357 输出 EMI 滤波等场合使用，不用于压电输入。

## 0.1 现有资源够不够？

**核心模块够用，但不能简单理解为“只加几个电容电阻”。**

够用的部分：

| 资源 | 结论 |
|---|---|
| Tang Nano 20K | GPIO 足够：矩阵 8 根、I2C 2 根、5 路峰值复位、调试信号都够 |
| ADS7830 | 8 通道刚好够基础方案：5 压电 + 1 FSR + 1 电位器 = 7 路，剩 1 路备用 |
| 5 片压电片 | 够做 5 个独立触发 |
| 1 片 FSR | 够做全局持续表情 |
| 4×4 矩阵 | 够做 12 音符 + 4 功能键 |
| MAX98357 + 无源扬声器 | 够做单声道音频输出 |

还需要补的分立器件（不是只有 R/C）：

- 5 路压电保护：BAT54S ×5、BAT85 ×5、3.3 V TVS/稳压管 ×5；
- 5 路峰值复位：2N7002 ×5、100 Ω ×5、100 kΩ ×5；
- 电阻：1 kΩ ×5、1 MΩ ×10、100 Ω ×10；
- 电容：1 nF ×5、100 nF ×10~15；
- 上拉：4.7 kΩ ×2（I2C）、10 kΩ ×4（矩阵列）；
- 电源：独立 5 V/1 A 电源或电源模块、100 µF/10 µF 去耦；
- 结构：一块小洞洞板/第二块面包板、压电片固定材料。

只有一件“可能被忽略”的大件：**MAX98357 建议用独立 5 V 供电**，
不要从 FPGA 的 3.3 V 稳压器直接取电，否则大音量时可能掉压/引入噪声。

如果以后要做“每弦独立 FSR 表情”，5 路 FSR + 5 路压电 + 电位器 = 11 路，
ADS7830 的 8 通道就不够了，需要第二片 ADC 或模拟多路开关；
那是扩展方案，不是当前基础方案。

- 磁珠 + 1 nF 是 EMI 滤波，不是为了“中和”尖峰。
- 不要把压电片直接接到 MAX98357 输出；压电片应走独立的传感器调理电路。

## 4. 压电片单路调理电路

```text
                         R_s 1kΩ 1/4W
Piezo ──┬── R_b 1MΩ ──/\/\/\──┬──────────────┬──────────► D_p BAT85 ──┬── R_a 100Ω ──► ADS7830 CHx
        │                     │              │                        │
       GND                    │              │                        ├── C_h 100nF ── GND
                              │              │                        ├── R_h 1MΩ ── GND
                              │              │                        └── Q1 2N7002 漏极
                              │              │                                  源极 ── GND
                              │              │                                  栅极 ── 100Ω ── FPGA GPIO
                              │              │                                            └── 100kΩ ── GND
                              │              │
                              │              ├── D1 BAT54S ── 3.3V
                              │              ├── D2 BAT54S ── GND
                              │              └── Z1 BZX84C3V3 ── GND
                              │
                         C_lp 1nF ── GND
```

各元件作用：

| 元件 | 作用 |
|---|---|
| `R_b` 1 MΩ | 压电片自身电容的直流泄放，避免电荷累积 |
| `R_s` 1 kΩ | 限制尖峰电流，保护钳位管和 FPGA |
| `D1/D2` BAT54S | 把节点夹在约 -0.3 V ~ 3.6 V |
| `Z1` 3.3 V 稳压/TVS | 吸收尖峰能量，保护钳位管 |
| `C_lp` 1 nF | 就近吸收高频，抑制振铃 |
| `D_p` BAT85 | 峰值检波，给 `C_h` 充电 |
| `C_h` 100 nF | 保持峰值，供 ADS7830 采样 |
| `R_h` 1 MΩ | 峰值缓慢泄放，τ≈100 ms |
| `Q1` 2N7002 | FPGA 读完峰值后拉低 `C_h`，准备下一次触发 |
| `R_a` 100 Ω | 隔离 ADC 采样电容 |

设计要点：

1. **钳位必须在连接器/面包板入口处**，不要等信号走过长线再到 FPGA。
2. `R_s` 建议 1/2 W，虽然尖峰很短，但瞬时功率大。
3. 如果压电片输出极性固定，半波峰值检波即可；如果正负峰都很大，
   可在 `R_s` 前加 100 nF 隔直 + 100 kΩ/100 kΩ 偏置到 1.65 V，再做全波检波（更复杂）。
4. 峰值保持后，FPGA 需要按“读 ADC → 拉高 Q1 放电 → 拉低 Q1”的顺序操作；
   不要一直让 Q1 导通，否则无法保持峰值。
5. 5 路压电片要有**独立阈值和独立峰值**，不能共用一个保持电容。

## 5. 关于“要不要加电感”的结论

| 位置 | 是否需要电感 | 说明 |
|---|---|---|
| 压电片输入 | **不需要** | 电感会与压电片电容谐振，可能放大尖峰；用限流+钳位+泄放 |
| 压电片作为发声器 | 不需要 | 用三极管/MOSFET 驱动，加基极/栅极电阻和钳位二极管 |
| MAX98357 输出到扬声器 | 可选磁珠 | 磁珠+1 nF 做 EMI 滤波，不是必需；长线时建议加 |
| 电源入口 | 可选磁珠 | 用于隔离数字噪声，不是用来吸收压电尖峰 |

压电片如果用作发声器（不是传感器），推荐驱动：

```text
FPGA GPIO ── 1kΩ ── NPN 基极（2N3904/S8050）
                   集电极 ── 压电片 ── 3.3V/5V
                   发射极 ── GND
压电片两端并 1MΩ + 双向钳位（BAT54S 到 0/3.3V）
```

不要用 FPGA 引脚直接驱动压电片，峰值电流和反向电压都可能损坏 IO。

## 6. 通道分配建议

ADS7830 有 8 个通道。为了**不破坏当前已经验证的 RTL**，建议：

| 通道 | 用途 |
|---|---|
| CH0 | FSR402 |
| CH1 | 电位器 |
| CH2~CH6 | 5 路压电峰值 |
| CH7 | 备用 |

当前 `project_params.svh` 就是 `FSR_CHANNEL=0`、`POT_CHANNEL=1`，testbench
也按这个映射验证过，所以这样接线可以继续使用现有代码。

如果团队坚持 `docs/device_Info_path.md` 里的“CH0~CH4 压电、CH5 FSR、CH6 电位器”
方案，则必须同步修改：

- `rtl/common/project_params.svh` 的通道常量（`FSR_ADC_CHANNEL`、
  `POT_ADC_CHANNEL`、`PIEZO_ADC_CHANNEL_BASE`）；
- `input_top.sv` 里 7 通道调度 `scan_idx` 对应的 `adc_ch_sel` 映射表；
- `tb_input_top.sv` 和 `tb_adc_ads7830.sv` 的期望值。

两种方案只能选一种，不能硬件按一套、软件按另一套。

## 9. 与当前 RTL 的对应关系

截至 2026-10-20，成员 2 的 RTL 已经实现：

- 5 路压电峰值读取、阈值、力度映射、自动 NOTE_OFF、防重复触发；
- 7 通道 ADC 轮询：CH0 FSR、CH1 电位器、CH2~CH6 压电、CH7 备用；
- 压电/矩阵事件仲裁：ALL_NOTES_OFF > 压电 > 矩阵普通事件；
- `MATRIX_MODE=1`：矩阵选根音/音区，压电触发；
- 9 个 testbench 全部通过。

板级/硬件侧仍需完成：

1. 按第 4 节制作 5 路压电保护/峰值保持电路。
2. 把 `piezo_peak_rst[4:0]` 接到 5 路 2N7002 栅极（5 根 FPGA GPIO，高有效）。
3. 确认 ADS7830 通道接线与 RTL 一致：
   CH0 FSR、CH1 电位器、CH2~CH6 压电、CH7 备用。
4. 成员 3 完成顶层、`.cst` 引脚约束和 5 V 功放供电。
5. 上板后用示波器先看每路钳位后的峰值波形，再接 FPGA。
6. 实测压电触发延迟、自动 NOTE_OFF 时间和端到端音频延迟。

> 压电片信号仍然必须先经过限流/钳位/峰值保持，不能直接接 FPGA 引脚。
> 当前 RTL 只负责读“已经调理好的 0~3.3 V 峰值”。
