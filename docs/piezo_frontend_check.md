# 压电单通道前端板上电与联调检查

版本：v1.0  
对应文件：`hardware/piezo_frontend/netlist.csv`  
目标：先验证 1 路压电的钳位、峰值保持、MOS 放电和 ADC 读数。

---

## 1. 上电前检查

不接压电片、不接 FPGA、不接 ADS7830 模块。

| 检查项 | 方法 | 期望 |
|---|---|---|
| `PIEZO0_P` 到 `CLAMP0` | 万用表电阻档 | 约 1kΩ |
| `CLAMP0` 到 GND | 电阻档 | 1MΩ 量级，不短路 |
| `PEAK0` 到 GND | 电阻档 | 1MΩ 量级，不短路 |
| `3V3` 到 GND | 电阻档 | 不短路 |
| `PIEZO_RST0` 到 GND | 电阻档 | 100kΩ 左右 |
| `Q1` 的 S 到 GND | 通断档 | 导通 |
| `D2` 阴极到 GND | 二极管档 | 正向约 0.6~0.8V，反向很高 |

如果 `3V3` 到 GND 短路，先不要上电，检查 `D1`、`D2`、`C4`、`C5` 的焊接。

---

## 2. 上电检查

只接 3.3V 和 GND，不接压电片、不接 FPGA。

| 测试点 | 期望 |
|---|---|
| `3V3` | 3.3V ±5% |
| `CLAMP0` | 接近 0V |
| `PEAK0` | 接近 0V |
| `ADC_CH2` | 接近 0V |
| `PIEZO_RST0` | 接近 0V（100k 下拉） |

如果 `CLAMP0` 一直在 3.3V 附近，检查 `D2` 是否接反或 `D1` 的 Pin2/Pin1 是否接错。

---

## 3. 敲击测试

接上压电片，`PIEZO_RST0` 保持低电平。

1. 用示波器看 `TP1`（`CLAMP0`）：
   - 正峰不应超过约 3.6V；
   - 负峰不应低于约 -0.3V。
2. 看 `TP2`（`PEAK0`）：
   - 敲击后电压上升；
   - 然后按 τ≈100ms 缓慢下降（100nF × 1MΩ）。
3. 看 `TP3`（`ADC_CH2`）：
   - 应跟随 `PEAK0`，只经过 100Ω + 100nF 的低通。

如果 `PEAK0` 不上升：

- `D3` BAT85 方向可能反了（阳极应接 `CLAMP0`，阴极接 `PEAK0`）；
- `C2` 虚焊；
- `R7`/`C3` 把节点拉死；
- `Q1` 一直导通（栅极被拉高或 MOS 损坏）。

如果 `PEAK0` 上升后马上掉到 0：

- `Q1` 的 G 可能没有下拉；
- `R3` 太小或焊错；
- 板面有助焊剂漏电；
- `D3` 反接。

---

## 4. MOS 放电测试

把 `PIEZO_RST0` 通过 100Ω 瞬间接到 3.3V，持续约 50µs，然后松开。

| 观察点 | 期望 |
|---|---|
| `PEAK0` | 迅速降到接近 0V |
| `ADC_CH2` | 跟随降到接近 0V |
| 松开 `RST` 后再次敲击 | 能重新建立峰值 |

如果 `PEAK0` 不下降：

- `Q1` 的 S/D 接反；
- `R4`/`R6` 虚焊；
- `PIEZO_RST0` 没有真正到 3.3V；
- 2N7002 损坏。

如果 `PEAK0` 一直为 0：

- `Q1` 的 G 被一直拉高；
- `R4` 短路到 3.3V；
- `Q1` 的 D/S 击穿。

---

## 5. 接 ADS7830 模块

1. `J3` 的 `3V3`、`GND` 接模块 `VCC`、`GND`；
2. `J3` 的 `ADC_CH2` 接模块 `CH2`；
3. 模块的 `SCL`、`SDA` **直接接 FPGA** 的 `adc_scl`、板级双向 `adc_sda`，不经过本板；
4. 模块未使用的 `CH0/CH1/CH3~CH7` 全部接 GND，避免悬空噪声。

上电后用 FPGA 读 CH2：

- 静止时 ADC 应接近 0；
- 敲击后 ADC 值应上升，然后按约 100ms 时间常数下降；
- 读到的最大值可能只有约 225~240，而不是 255，因为 BAT85 有正向压降，这是正常的。

---

## 6. 与 RTL 联调

RTL 默认：

```text
PIEZO_BASE_CH   = 2
PIEZO_THRESH    = 20
PIEZO_OFF_MS    = 500
PIEZO_RETRIG_MS = 50
```

对应关系：

| 硬件 | RTL |
|---|---|
| `ADC_CH2` | 模拟输出，接 ADS7830 CH2；RTL 里对应 P0 |
| `PIEZO_RST0` | `piezo_peak_rst[0]`，本板唯一直接来自 FPGA 的数字控制 |
| ADS7830 `SCL` | `adc_scl`（模块直接接 FPGA，不经过本板） |
| ADS7830 `SDA` | 板级 `adc_sda`（模块直接接 FPGA，不经过本板） |

如果读到的峰值偏低：

- 先确认 `PIEZO_THRESH` 是否过高；
- 用示波器看 `PEAK0` 实际峰值；
- 适当降低 `PIEZO_THRESH` 或调整 `calc_velocity` 的映射；
- 不要直接把阈值设成 0，否则噪声会误触发。

如果一直触发：

- `PEAK0` 是否一直高于阈值；
- `R3` 是否虚焊；
- `Q1` 是否没有放电；
- `PIEZO_RST0` 是否没有产生 50µs 脉冲。

---

## 7. 安全与常见错误

1. **不要用 5V 给 ADS7830 或本板供电**，全部 3.3V。
2. 压电片 `P-` 必须接 GND，不能悬空。
3. `D2` 齐纳阴极接 `CLAMP0`，阳极接 GND；接反会把正峰钳在 0.7V。
4. `D3` BAT85 阳极接 `CLAMP0`，阴极接 `PEAK0`；接反没有峰值。
5. `Q1` 2N7002 的 S 接 GND，D 接保持电容；S/D 接反会导致峰值保持失效。
6. `J3` 的 `ADC_CH2` 只能接模块 CH2，不要接到 3.3V 或 GND。
7. 焊接后清洗助焊剂，尤其是 `PEAK0` 高阻节点。
