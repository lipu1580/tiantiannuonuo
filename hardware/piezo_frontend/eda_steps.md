# 立创EDA专业版操作步骤（单通道压电前端）

对应文件：`netlist.csv`、`BOM.csv`、`layout.md`  
目标：画出 1 路纯模拟前端板，保留 `PIEZO_RST0` 放电控制，ADS7830 模块不放在板上。

---

## 0. 新建工程

1. 打开立创EDA专业版；
2. 新建工程，名称例如 `piezo_frontend_v1`；
3. 添加“原理图”和“PCB”；
4. 图纸大小 A4 即可。

---

## 1. 先放四个连接器

在元件库搜索并放置：

| 位号 | 搜索词 | 封装 | 说明 |
|---|---|---|---|
| `J1` | `KF301-2P` 或 `KF128-2P` | `KF301-2P` / `TerminalBlock_bornier-2_P5.08mm` | 压电输入 |
| `J2` | `HDR-M-2.54_1x2` | `HDR-M-2.54_1x2` | `PIEZO_RST0` + GND |
| `J3` | `HDR-M-2.54_1x4` | `HDR-M-2.54_1x4` | `3V3`、`GND`、`ADC_CH2`、`GND` |
| `TP1~TP4` | `TestPoint` | `TestPoint` | 测试点 |

> 不要用“输入/输出端口”代替连接器。端口没有封装，3D 里看不到。

---

| `R2` | `1M` | `R_0805` | 压电片泄放 |
| `R3` | `1M` | `R_0805` | 保持电容泄放 |
| `R8` | `1M` | `R_0805` | 钳位节点偏置 |
| `R4` | `100` | `R_0805` | 栅极串联 |

| `R6` | `100` | `R_0805` | 放电限流 |
| `R7` | `100` | `R_0805` | ADC 隔离 |
| `C1` | `1nF` | `C_0805` | 高频滤波 |
| `C2` | `100nF` | `C_0805` | 峰值保持 |

---

## 3. 关键符号检查

放置后先双击器件，确认引脚编号与数据手册一致：

### BAT54S（SOT-23）

```text
Pin1 = A1（内部二极管1阳极）  -> GND
Pin2 = K2（内部二极管2阴极）  -> 3V3
Pin3 = COM（公共端）          -> CLAMP0
```

如果库里的符号不是这个定义，换一个 `BAT54S` 符号，或手动改引脚映射。

### BZX84C3V3（SOT-23）

```text
A（阳极）  -> GND
K（阴极）  -> CLAMP0
NC          -> 悬空
```

本数据手册（R+O BZX84C2V4~C75）的物理映射：`Pin1=A`、`Pin2=NC`、`Pin3=K`。如果 EDA 符号不是这个映射，先改符号或换库。

如果符号只有 2 个引脚，也可以；封装仍用 SOT-23，Pin3 不接。

### 2N7002（SOT-23）

```text
Pin1 = G -> GATE0
Pin2 = S -> GND
Pin3 = D -> DRAIN0
```

S 必须接 GND，D 通过 `R6` 接 `PEAK0`。

---

## 4. 用网络标签连线

不要把所有线都画得很长，建议先放网络标签：

| 网络 | 连接的引脚 |
|---|---|
| `PIEZO0_P` | `J1.1`、`R1.1`、`R2.1` |
| `CLAMP0` | `R1.2`、`D1.3`、`D2.2`、`C1.1`、`R8.1`、`D3.1`、`TP1` |
| `PEAK0` | `D3.2`、`C2.1`、`R3.1`、`R6.1`、`R7.1`、`TP2` |
| `DRAIN0` | `Q1.3`、`R6.2` |
| `GATE0` | `Q1.1`、`R4.2`、`R5.1` |
| `ADC_CH2` | `R7.2`、`C3.1`、`J3.3`、`TP3` |
| `PIEZO_RST0` | `J2.1`、`R4.1` |
| `3V3` | `J3.1`、`C4.1`、`C5.1` |
| `GND` | 所有 GND 引脚 |

操作建议：

1. 先给每个节点放 `网络标签`；
2. 再用短导线把标签接到引脚；
3. 所有 GND 用 **GND 电源符号**；
4. `D2` 的 Pin3 放一个 **No Connect（不连接）** 标记，避免 ERC 报错；
5. 不要用“端口”符号代替网络标签。

---

## 5. ERC 检查

运行“设计规则检查/ERC”，重点看：

- 是否有未连接引脚（除了 `D2.3` 的 NC）；
- 是否有电源网络短路；
- 是否有输出冲突；
- 网络名是否拼写一致（`CLAMP0` 不要写成 `CLAMP_0`）。

如果 ERC 报 `D2.3` 未连接，放 No Connect 标记即可。

---

## 6. 转 PCB

1. “设计 -> 转换原理图到 PCB”；
2. 画板框：建议 **35 mm × 50 mm**；
3. 四角加 M2.5 安装孔；
4. 按 `layout.md` 摆放：
   - `J1` 放左边；
   - `R1/D1/D2/C1/R2/R8` 靠近 `J1`；
   - `D3/C2/R3` 放中间；
   - `Q1/R4/R5/R6` 靠中间偏右；
   - `R7/C3/J3` 放右边；
   - `C4/C5` 放 `J3` 附近；
   - `TP1~TP4` 放板边或空白处。
5. 底层整片铺 GND；
6. 先布 `CLAMP0`、`PEAK0`、`ADC_CH2`，再布电源和 RST；
7. 打地过孔，连接上下层地。

---

## 7. DRC 与 3D 检查

DRC 建议：

- 线宽/间距：6/6 mil；
- 过孔：0.3/0.6 mm；
- 板边间距：0.3 mm 以上；
- 丝印不要压焊盘。

3D 检查：

- `J1/J2/J3` 应能看到实际焊盘/针脚；
- `BAT54S/BZX84C3V3/2N7002` 应能看到 SOT-23；
- `TP1~TP4` 可能没有 3D 模型，正常；
- 网络标签/端口不会出现在 3D。

---

## 8. 导出 Gerber

“制造 -> 导出 Gerber”，检查：

- 顶层/底层铜；
- 阻焊；
- 丝印；
- 钻孔；
- 板框。

如果只打板自己焊，导出 Gerber 即可；如果还要嘉立创 SMT，再导出 BOM 和坐标文件。

---

## 9. 下单前最后检查

- [ ] `J1.2` 接 GND；
- [ ] `D1` 的 Pin3 接 `CLAMP0`，Pin1 接 GND，Pin2 接 3V3；
- [ ] `D2` 阴极接 `CLAMP0`，阳极接 GND；
- [ ] `D3` 阳极接 `CLAMP0`，阴极接 `PEAK0`；
- [ ] `Q1` 的 S 接 GND，D 通过 `R6` 接 `PEAK0`；
- [ ] `R1` 是 1W；
- [ ] `ADC_CH2` 只接 `J3.3`，没有接 3V3/GND；
- [ ] `D2.3` 已标 NC；
- [ ] 板框、安装孔、丝印完整。

---

## 10. 常见错误

| 现象 | 原因 |
|---|---|
| 3D 里看不到接口 | 用了端口/网络标签，不是连接器 |
| ERC 报 D2.3 未连接 | 没放 No Connect |
| 峰值一直为 0 | `D3` 反接，或 `Q1` 一直导通 |
| 正峰只有 0.7V | `D2` 齐纳接反 |
| 峰值掉得快 | `C2` 虚焊、`R3` 太小、板面漏电 |
| ADC 读数不动 | `J3.3` 没接到模块 CH2，或模块未用通道悬空 |
| 一上电 3V3 短路 | `D1`/`D2`/`C4`/`C5` 焊接短路 |

---

## 11. 与 RTL 的最终边界

```text
FPGA RTL ──PIEZO_RST0──► 本板 MOS
本板 ADC_CH2 ──► ADS7830 CH2
ADS7830 SCL/SDA ──► FPGA
```

本板不需要 SCL/SDA，也不需要任何 `event_*` 或音频信号。
