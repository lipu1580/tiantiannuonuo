# 单通道压电前端板布局与走线

版本：v1.0  
适用：`netlist.csv` 对应的单通道板  
建议板尺寸：**35 mm × 50 mm**（单通道）；如果直接画 5 路，建议 **80 mm × 60 mm**，先只焊 1 路。

---

## 1. 布局顺序

从左到右按信号流摆：

```text
J1 压电输入
  -> R1 1k
  -> CLAMP0 节点（D1/BAT54S + D2/BZX84 + C1 + R8）
  -> D3 BAT85
  -> PEAK0 节点（C2 + R3）
  -> Q1 放电 + R6
  -> R7 100Ω
  -> ADC_CH2 + C3
  -> J3 ADS7830 模块
```

建议位置：

| 区域 | 器件 |
|---|---|
| 板左边缘 | `J1` 压电螺钉端子 |
| J1 右侧 5 mm 内 | `R1`、`R2`、`D1`、`D2`、`C1`、`R8` |
| 板中部 | `D3`、`C2`、`R3` |
| 板中部偏右 | `Q1`、`R4`、`R5`、`R6` |
| 板右边缘 | `R7`、`C3`、`J3` |
| 板右下角 | `C4`、`C5` |
| 板边/空白处 | `TP1`~`TP4` 测试点 |

`J2`（RST）靠近 `Q1` 放置，走线短。

---

## 2. 关键节点走线

### 2.1 高压节点 `PIEZO0_P` / `CLAMP0`

- `PIEZO0_P` 到 `R1` 的走线尽量短；
- `R1` 之后的 `CLAMP0` 节点是高压钳位点，**走线短、粗**（建议 0.4 mm 以上）；
- `D1`、`D2`、`C1`、`R8` 的地回路要就近回到 GND；
- 不要把 `CLAMP0` 走到数字信号旁边。

### 2.2 高阻节点 `PEAK0`

- `D3` 阴极到 `C2`、`R3`、`Q1` 漏极、`R7` 的节点是**高阻节点**，最容易受漏电和噪声影响；
- 走线尽量短，周围不要走数字信号/时钟；
- `C2` 尽量靠近 `D3` 和 `Q1`；
- 如果板子空间允许，`PEAK0` 周围可铺 GND 保护，但不要形成漏电通路；
- 焊接后清洗助焊剂，避免表面漏电导致峰值掉得快。

### 2.3 ADC 输入 `ADC_CH2`

- `R7` 靠近 `PEAK0`，`C3` 靠近 `J3`；
- `ADC_CH2` 走线尽量短，远离数字信号；
- 如果 `J3` 到 ADS7830 模块用杜邦线，尽量短（<10 cm）；
- ADS7830 模块的 SCL/SDA 直接接 FPGA，不经过本板。

### 2.4 地

- 底层整片铺 GND；
- 模拟部分（`CLAMP0`、`PEAK0`、`ADC_CH2`）的地在 `J3`/ADS7830 模块附近单点汇合；
- `J1` 的 `P-` 在连接器附近直接接到 GND 平面；
- `Q1` 源极、`C2` 下端、`R3` 下端、`C3` 下端、`C1` 下端要就近打地过孔。

---

## 3. 线宽与过孔

| 类型 | 建议 |
|---|---|
| 普通信号 | 0.25 mm |
| `CLAMP0` / `PIEZO0_P` | 0.4 mm 以上 |
| 3V3 | 0.5 mm |
| GND | 地平面 + 多打地过孔 |
| 过孔 | 0.3/0.6 mm |
| 间距 | 6/6 mil 以上 |

---

## 4. 测试点

| 测试点 | 网络 | 用途 |
|---|---|---|
| `TP1` | `CLAMP0` | 看钳位后波形，确认不超过约 3.6V、负峰不低于约 -0.3V |
| `TP2` | `PEAK0` | 看峰值保持和泄放曲线 |
| `TP3` | `ADC_CH2` | 看 ADC 输入 |
| `TP4` | `GND` | 示波器地 |

测试点用 1.0~1.5 mm 焊盘即可，丝印标清楚。

---

## 5. 5 路扩展

如果直接画 5 路板：

- 把上面的单路块复制 5 份，横向排列；
- 每路独立：`R1/R2/D1/D2/C1/R8/D3/C2/R3/Q1/R4/R5/R6/R7/C3`；
- 5 路共用：`3V3`、`GND`、`C4`、`C5`；
- `J3` 扩展为 5 个 `ADC_CH2~CH6` + GND 的接口，或直接用 1x12 排针；
- `J2` 扩展为 `PIEZO_RST0~4 + GND` 的 1x6 排针；
- ADS7830 模块的 SCL/SDA 仍然直接接 FPGA；如果以后把模块固定在板上，再加 I2C 排针。
- 5 路布局保持完全对称，方便对照调试。

**第一次打样建议直接画 5 路板，只焊 P0；验证通过后再补焊另外 4 路。**
