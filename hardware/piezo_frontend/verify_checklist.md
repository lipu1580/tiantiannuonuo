# 单通道压电前端电路图检查清单

对应版本：纯前端 v1（不含板上 ADS7830，只有 `PIEZO_RST0` 数字控制）  
对应网表：`netlist.csv`

---

## 1. 原理图 ERC

在立创EDA里运行 ERC/设计规则检查，重点看：

- [ ] 没有未连接引脚（`D2.3` 除外，应放 No Connect）
- [ ] 没有 3V3 与 GND 短路
- [ ] 没有输出-输出冲突
- [ ] 网络名没有拼写不一致
- [ ] `J1/J2/J3` 每个引脚都有连接

ERC 只能查“连接关系”，查不出器件极性/引脚映射错误，所以还要做下面的检查。

---

## 2. 网表逐项对比

导出立创EDA网表，或者直接对照原理图检查以下 10 个网络：

| 网络 | 必须连接的引脚 |
|---|---|
| `PIEZO0_P` | `J1.1`、`R1.1`、`R2.1` |
| `CLAMP0` | `R1.2`、`D1.3`、`D2.2`、`C1.1`、`R8.1`、`D3.1`、`TP1` |
| `PEAK0` | `D3.2`、`C2.1`、`R3.1`、`R6.1`、`R7.1`、`TP2` |
| `DRAIN0` | `Q1.3`、`R6.2` |
| `GATE0` | `Q1.1`、`R4.2`、`R5.1` |
| `PIEZO_RST0` | `J2.1`、`R4.1` |
| `ADC_CH2` | `R7.2`、`C3.1`、`J3.3`、`TP3` |
| `3V3` | `J3.1`、`C4.1`、`C5.1` |
| `GND` | `J1.2`、`R2.2`、`D1.1`、`D2.1`、`C1.2`、`R8.2`、`C2.2`、`R3.2`、`Q1.2`、`R5.2`、`C3.2`、`C4.2`、`C5.2`、`J2.2`、`J3.2`、`J3.4`、`TP4` |
| `NC` | `D2.3` 悬空 |

如果某个网络多连/少连一个引脚，先改原理图，不要带到 PCB。

## 3. 器件极性与引脚映射

### D1 BAT54S

- [ ] Pin1 = `GND`
- [ ] Pin2 = `3V3`
- [ ] Pin3 = `CLAMP0`

注意：不是 Pin1/Pin2 随便接，Pin3 是公共端。

### D2 BZX84C3V3

- [ ] A（阳极）= `GND`
- [ ] K（阴极）= `CLAMP0`
- [ ] NC = 悬空

### D3 BAT85

- [ ] Pin1（阳极）= `CLAMP0`
- [ ] Pin2（阴极）= `PEAK0`

### Q1 2N7002

- [ ] Pin1 G = `GATE0`
- [ ] Pin2 S = `GND`
- [ ] Pin3 D = `DRAIN0`

### J1/J2/J3

- [ ] `J1.1 = PIEZO0_P`，`J1.2 = GND`
- [ ] `J2.1 = PIEZO_RST0`，`J2.2 = GND`
- [ ] `J3.1 = 3V3`，`J3.2 = GND`，`J3.3 = ADC_CH2`，`J3.4 = GND`

---

## 4. 不上电静态检查

用万用表电阻档，不接压电片、不接电源：

- [ ] `PIEZO0_P` 到 `CLAMP0`：约 1kΩ
- [ ] `PIEZO0_P` 到 `GND`：约 1MΩ（R2）
- [ ] `CLAMP0` 到 `GND`：1MΩ 量级，不短路
- [ ] `PEAK0` 到 `GND`：1MΩ 量级，不短路
- [ ] `3V3` 到 `GND`：不短路
- [ ] `PIEZO_RST0` 到 `GND`：约 100kΩ（R5）
- [ ] `Q1.S` 到 `GND`：导通

---

## 5. 上电静态检查

只接 3.3V 和 GND：

- [ ] `3V3` = 3.3V ±5%
- [ ] `CLAMP0` ≈ 0V
- [ ] `PEAK0` ≈ 0V
- [ ] `ADC_CH2` ≈ 0V
- [ ] `PIEZO_RST0` ≈ 0V（R5 下拉）

如果 `CLAMP0` 在 3.3V 附近，检查 D2 是否接反或 D1 的 Pin1/Pin2 是否接错。

---

## 6. 动态波形检查

接压电片，用示波器：

- [ ] `TP1/CLAMP0`：正峰 ≤ 约 3.6V，负峰 ≥ 约 -0.3V
- [ ] `TP2/PEAK0`：敲击后上升，然后按 τ≈100ms 缓慢下降
- [ ] `TP3/ADC_CH2`：跟随 `PEAK0`，只是经过 100Ω + 100nF 低通
- [ ] 给 `PIEZO_RST0` 加 3.3V 约 50µs：`PEAK0` 迅速降到 0V
- [ ] 松开 `PIEZO_RST0` 后再次敲击：能重新建立峰值

只有万用表时：

- [ ] 敲击后 `PEAK0` 电压上升，然后慢慢下降
- [ ] 把 `PIEZO_RST0` 瞬间接 3.3V，`PEAK0` 掉到 0V

---

## 7. PCB DRC 检查

- [ ] 线宽/间距 6/6 mil 以上
- [ ] 过孔 0.3/0.6 mm
- [ ] 板边间距 ≥0.3 mm
- [ ] 底层整片 GND
- [ ] `CLAMP0`/`PEAK0` 走线短，远离数字信号
- [ ] `J1` 的 `P-` 就近接 GND
- [ ] 丝印不压焊盘
- [ ] 3D 中能看到 `J1/J2/J3` 和主要器件

---

## 8. 与 ADS7830 / RTL 联调

- [ ] `J3.3/ADC_CH2` 接 ADS7830 `CH2`
- [ ] 模块 `VCC/GND` 接 `J3.1/J3.2`
- [ ] 模块 `SCL/SDA` 直接接 FPGA
- [ ] 未用 ADC 通道接 GND
- [ ] RTL `PIEZO_BASE_CH=2`
- [ ] RTL `piezo_peak_rst[0]` 接 `J2.1`
- [ ] 敲击后 ADC 值上升，静止时接近 0
- [ ] 最大值约 225~240 属正常（BAT85 正向压降）

---

## 9. 常见错误

| 现象 | 可能原因 |
|---|---|
| 3D 看不到接口 | 用了端口/网络标签，不是连接器 |
| `CLAMP0` 只有 0.7V | D2 齐纳接反 |
| `PEAK0` 一直为 0 | D3 反接、C2 虚焊、Q1 一直导通 |
| `PEAK0` 掉得很快 | C2 虚焊、R3 焊错、板面漏电 |
| `PEAK0` 不下降 | Q1 S/D 接反、R6 虚焊、RST 没到 3.3V |
| ADC 读数不动 | `J3.3` 没接模块 CH2、模块未用通道悬空 |
| 上电 3V3 短路 | D1/D2/C4/C5 焊接短路 |
